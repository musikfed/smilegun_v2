# SMILE·GUN v2 — қазақша қысқаша нұсқаулық

SMILE·GUN — веб-камера арқылы қол мен бет қимылдарын пайдаланатын жергілікті браузерлік аркада. Тілді негізгі мәзірден таңдауға болады, таңдау браузерде сақталады.

**Басқару:** қол шаршыны жылжытады; жұдырық бір оқ атады; ауызды ашу шашыраңқы атыс береді; жыпылық SUPER қуатын жинайды; күлімсіреу кездейсоқ 10–25 секунд, +1 өмір және 45 секунд сауыт береді; SUPER 100% болса жаңа күлімсіреу алаңды тазартады; ✌ елес режимі; 👐 кідіріс/жалғастыру.

Раундтар: **ТИР → ГАЛАКТИКА → ЖАЛТАРУ → КӨЛДЕНЕҢ ҰШУ**. Бонуспен қалған уақыт 50 секундтан аспайды.

Windows іске қосу:

```powershell
cd D:\smilegun
uv run --python 3.12 python app.py
```

Телефоннан Wi‑Fi арқылы ойнау үшін `run_mobile.ps1` қолданыңыз, `.smilegun-certs` сертификатын сенімді етіңіз және көрсетілген HTTPS мекенжайын ашыңыз. Толық техникалық құжаттама түбірдегі ағылшын `README.md` файлында.

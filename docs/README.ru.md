# SMILE·GUN v2 — краткая инструкция на русском

SMILE·GUN — локальная браузерная аркада с управлением рукой и лицом через веб-камеру. Выбор языка находится в главном меню и запоминается браузером.

**Управление:** рука двигает квадрат; кулак стреляет; открытый рот даёт рассыпной залп; моргания заряжают SUPER; улыбка добавляет случайные 10–25 секунд, жизнь и броню на 45 секунд; при 100% SUPER новая улыбка очищает поле; ✌ включает «призрака»; 👐 ставит игру на паузу/продолжает.

Раунды: **ТИР → ГАЛАКТИКА → УКЛОНЕНИЕ → ЛЕНТОЧНЫЙ ПОЛЁТ**. Остаток времени после бонусов не превышает 50 секунд.

Запуск на ПК:

```powershell
cd D:\smilegun
uv run --python 3.12 python app.py
```

Для смартфона по Wi‑Fi используйте `run_mobile.ps1`, установите локальный сертификат из `.smilegun-certs` и откройте показанный HTTPS-адрес. Основная техническая документация находится в корневом `README.md` на английском.

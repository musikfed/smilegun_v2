# SMILE·GUN v2 — 한국어 빠른 안내

SMILE·GUN은 웹캠으로 손과 얼굴 동작을 인식하는 로컬 브라우저 아케이드 게임입니다. 메인 메뉴에서 언어를 선택할 수 있으며 브라우저가 선택을 저장합니다.

**조작:** 손으로 사각형 이동; 주먹은 단발; 입 벌리기는 산탄; 눈깜빡임은 SUPER 충전; 미소는 무작위 10–25초, +1 생명, 45초 방어막; SUPER 100%에서 새로운 미소를 지으면 화면 정리; ✌ 유령 모드; 👐 일시정지/계속.

라운드: **사격장 → 갤럭시 → 회피 → 횡스크롤 비행**. 보너스 적용 후 남은 시간은 최대 50초입니다.

Windows 실행:

```powershell
cd D:\smilegun
uv run --python 3.12 python app.py
```

휴대폰에서 Wi‑Fi로 전면 카메라를 사용할 때는 `run_mobile.ps1`을 실행하고 `.smilegun-certs`의 로컬 인증서를 신뢰한 뒤 표시된 HTTPS 주소를 여세요. 전체 기술 문서는 루트의 영어 `README.md`를 참고하세요.
